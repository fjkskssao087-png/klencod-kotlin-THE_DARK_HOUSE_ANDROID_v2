مشروع THE DARK HOUSE للأندرويد - نسخة تأسيسية قابلة للتطوير.
افتح Klencod IDE ثم استيراد مشروع من ZIP واختر هذا الملف.
المشروع Android Gradle أصلي بلغة Java مع لعبة Babylon.js داخل WebView.
يتطلب اتصال إنترنت لتحميل محرك Babylon.js من CDN عند التشغيل.
بعد الاستيراد انتظر Gradle Sync ثم اختر Build APK.
لم يتم اختبار البناء داخل Klencod أو على جهازك؛ أرسل صورة أي خطأ يظهر.
التحكم: عصا اليسار للحركة، سحب يمين الشاشة للنظر، تفاعل لفتح الباب، ركض للحركة السريعة.
هذه نسخة أولية وليست لعبة نهائية؛ يمكن إضافة وحش وأصوات وغرف ومهام في التطوير القادم.

تحديث الإضاءة: رفع وضوح المشهد وإضافة نموذج كشاف يدوي ظاهر أمام اللاعب، مع شعاع ضوئي يتحرك مع اتجاه الكاميرا واهتزاز خفيف أثناء المشي.
